# 机器人与群资料

[API 目录](../%E6%96%87%E6%A1%A3%E7%9B%AE%E5%BD%95.md) · 包 `top.yzljc.atricore.platform.qq`

## 机器人资料

Provider 启动 QQ 服务时调用 `QQBot.fetchBotInfo()`，业务也可主动刷新。该方法同步访问平台，并更新静态资料字段

| 字段 | 内容 |
| --- | --- |
| BOT_UNIONID | 平台返回的机器人 union_openid，可能为空 |
| BOT_AVATAR_URL | 头像地址 |
| BOT_NAME | 名称 |
| BOT_SHARE_LINK | 分享链接 |
| BOT_WELCOME_MSG | 平台欢迎语 |
| BOT_UIN | 机器人 QQ 号码，可能为空 |

这些字段是最近一次刷新结果，不会每次读取都请求平台，也不表示业务默认加群欢迎配置

## 自定义分享链接

`top.yzljc.atricore.chat.official.ShareBot` 封装 `POST /v2/generate_url_link`，使用当前 Provider 的 QQ 接口地址与令牌

```java
import top.yzljc.atricore.chat.official.ShareBot;

String shareLink = ShareBot.generateShareLink(userOpenId);
if (shareLink != null) {
    String shortCode = ShareBot.getShareShortCode(shareLink);
}
```

| 方法 | 参数 | 返回与行为 |
| --- | --- | --- |
| `generateShareLink(callbackData)` | 业务回调标识，不得为 null，内容须符合平台 callback_data 要求 | 同步请求生成链接，失败或响应缺少有效链接时返回 null |
| `getShareShortCode(shareLink)` | 平台返回的分享链接，允许 null | 提取最后一个斜杠后的短码；输入为空、不含斜杠或以斜杠结尾时返回 null，不请求平台 |

生成方法每次调用均请求平台。链接缓存、回调标识的业务含义、邀请关系和奖励由运行服务处理；主项目使用邀请人的 OpenID 作为回调标识，在 `OfficialFriendAddEvent.getSceneParam()` 中读取后处理邀请记录

## 群资料

```java
import top.yzljc.atricore.platform.qq.QQBot;

var result = QQBot.fetchGroupProfileDetailed(groupOpenId);
if (result.profile() != null) {
    System.out.println(result.profile().groupName());
} else if (result.isDefunctGroup()) {
    System.out.println("平台返回群失效状态");
} else {
    System.err.println("群资料查询失败: " + result.errCode());
}
```

| 方法 | 返回与行为 |
| --- | --- |
| `fetchGroupProfile(groupOpenId)` | GroupProfile，失败返回 null |
| `fetchGroupProfileDetailed(groupOpenId)` | GroupProfileResult，含资料和错误码 |
| `fetchGroupProfileDetailed(groupOpenId, logOnlyOnError)` | true 时仅记录失败请求日志 |

::: tip 批量查询群资料
一次查询分别访问机器人群内状态和群资料接口，各自经过限流等待；调用是同步的，遍历大量群时应使用业务调度任务，不在消息处理线程连续阻塞查询
:::

## QQGroup

[源码](https://github.com/Atri-DevTeam/AtriBot/blob/2a1ea98a2ed52802047b4e2ff266cbeed1be767b/atri-core/src/main/java/top/yzljc/atricore/platform/qq/QQGroup.java) · 群上下文及同步操作入口

群事件通过 `getGroup()` 提供该对象，`QQCommandSender.getGroup()` 在群聊中使用同一实例。手动创建时传入群 OpenID，可同时传入平台提供的群统一 OpenID

```java
import top.yzljc.atricore.platform.qq.QQGroup;
import top.yzljc.atricore.chat.official.RT;

var group = new QQGroup(groupOpenId, unionGroupOpenId);
group.replyMessage(RT.message(messageId), "处理完成");
```

| 方法 | 返回与行为 |
| --- | --- |
| `QQGroup(groupOpenId)` | 创建群对象，群统一 OpenID 为 null |
| `QQGroup(groupOpenId, unionGroupOpenId)` | 保存两种群标识 |
| `of(groupOpenId)` / `of(groupOpenId, unionGroupOpenId)` | 对应构造方法的静态入口 |
| `getGroupOpenId()` / `getGroupId()` | 返回相同的群 OpenID |
| `getUnionGroupOpenId()` | 返回群统一 OpenID，未提供时为 null |
| `fetchGroupProfile()` | 同步请求 `GroupProfile`，失败返回 null |
| `sendMessage(content)` | 主动发送，支持 String、Markdown、ImageComponent、Ark 和 Card，返回消息 ID |
| `replyMessage(rt, content)` | 使用 `RT` 被动回复，支持上述五种内容类型，返回消息 ID |
| `replyMessage(rt, userOpenId, markdown)` | 被动回复 Markdown 并提及指定成员 |
| `sendMessage(fileType, file)` | 发送本地文件，`file` 为 Path，返回消息 ID |
| `replyMessage(rt, fileType, file)` | 使用消息或事件来源回复本地文件 |
| `recallMessage(messageId)` | 撤回本群内机器人发送的消息，返回 boolean |
| `getMemberList(cursor)` | 请求成员分页，返回 `GroupMember.MemberListResult`，失败返回 null |
| `getMemberInfo(memberOpenId)` | 请求成员资料，返回 `GroupMember.MemberInfo`，失败返回 null |
| `mute(memberOpenId, duration)` | 设置成员禁言，返回 boolean |
| `updateMute(memberOpenId, duration)` | 修改已有禁言到期时间，返回 boolean |
| `unmute(memberOpenId)` | 解除成员禁言，返回 boolean |
| `queryMuteState()` | 请求禁言状态，返回 `Mute.MuteStateResult`，失败返回 null |
| `kick(memberOpenId)` | 移除成员，默认不加入成员黑名单 |
| `kick(memberOpenId, addToMemberBlacklist)` | 移除成员并选择是否加入成员黑名单，返回 boolean |
| `kickMembers(memberOpenIds, addToMemberBlacklist)` | 自动分批移除，全部成功时返回 true，部分成功不回滚 |

构造对象和读取标识只访问内存，平台查询在调用对应操作方法时执行。消息发送沿用 [群消息](../QQ%E6%B6%88%E6%81%AF/%E7%BE%A4%E6%B6%88%E6%81%AF.md) 的发送及失败处理，禁言时长为 Duration，成员管理授权及参数要求见 [群管理](../QQ%E7%BE%A4%E7%AE%A1%E7%90%86/%E7%9B%AE%E5%BD%95.md)

群统一 OpenID 用于读取平台上报的统一标识；发送和管理接口仍使用 `groupOpenId`

## GroupProfile

| 字段 | 说明 |
| --- | --- |
| memberOpenId | 机器人在群内的成员标识 |
| joinTime | 机器人入群时间 |
| allowProactiveMsg | 是否允许主动消息 |
| receiveMsgSetting | ONLY_MENTION、MENTION_AND_CONTEXT 或 ALL |
| memberRole | 平台角色 |
| groupId | 群 OpenID，尽管字段名为 groupId，也不是群号码 |
| groupName | 群名称 |
| groupFingerMemo | 群简介 |
| groupClassText | 群分类 |
| groupTags | 标签列表 |
| groupMemberNum | 成员数 |

`GroupProfile.Scope.from(value)` 将平台字符串转为枚举，未知值回退 ONLY_MENTION；`getJsonValue()` 返回对应平台字符串

`GroupProfileResult.isDefunctGroup()` 按当前实现登记的失效错误码判断，普通网络失败不应据此删除群数据
